# homebrew-figstudio

Homebrew tap for [figstudio](https://github.com/pelvo/figstudio) (macOS, Apple silicon).

```sh
brew install --cask pelvo/figstudio/figstudio
```

Installs `figstudio.app` and puts `figstudio-cli` and `figstudio-mcp` on the PATH.
The cask follows the latest GitHub release; `.github/workflows/bump.yml` updates it.
